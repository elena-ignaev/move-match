Privacy and data

What MoveMatch stores, where, and for how long

What is uploaded

  • Reference videos you upload (the original file).
  • Practice recordings: the camera video recorded while you press Record, without sound. The microphone is never used. Nothing is recorded during countdowns, previews or ghost practice without recording.
  • A small timing log of the reference playback during a recording (play, pause, buffering and the reference time of each displayed frame), your chosen section, speed and mirror settings, and your browser's name.

Where it is stored

Everything stays on the server running MoveMatch, in its storage/ folder and a SQLite database. {% if not public_demo %}In local mode that server is your own computer.{% endif %} From each video the server derives a browser-playable copy and a file of body-landmark coordinates (33 points per frame, computed by Google's MediaPipe model running on this server). Nothing is sent to third-party services.

Who can see it

{% if public_demo %}

Your browser gets a random, anonymous session id. Only that browser can see the attempts and videos it created. Clearing your cookies means you can no longer open them (they are still deleted on schedule).

{% else %}

This server runs in single-user local mode: anyone who can open this page on this computer can see all videos and attempts.

{% endif %}

When it is deleted

  • You can delete any attempt (on its page) or any reference video with all its attempts (on the video page) at any time. Deletion removes the files and the database rows immediately.
  • The raw browser recording is deleted as soon as its replay copy is created.
    • {% if limits.retention_h %}
  • On this demo, uploads and recordings are deleted automatically after {{ limits.retention_h|int }} hours.
    • {% else %}
  • Otherwise files are kept until you delete them.
    • {% endif %}
