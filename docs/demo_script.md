# Demo video: shot list (60–90 seconds)

Goal: show one complete, successful journey, and one honest limitation, without narration over every step.

| Time | Shot | Say / caption |
|---|---|---|
| 0–8 s | Me in a dance room; text "Learning choreography alone is hard" | "100+ hours to clean a 4.5-minute performance" |
| 8–18 s | Upload a 20 s clip → progress bar → finished video with skeleton | "Pretrained pose detection, music kept" |
| 18–30 s | Practise page: set section 0:10–0:16, loop at 0.5×, mirror view on, step a frame | "Slow it down, loop it, mirror it" |
| 30–42 s | Record page: guide box, 5-4-3-2-1 countdown, dancing with the ghost overlay | "Record with a countdown and a ghost" |
| 42–58 s | Attempt page: side-by-side replay, then feedback: "0.35 s behind", one flagged moment → "Show in replay" | "Timing and shape, separately" |
| 58–72 s | Try again → second attempt: on time, moment now "Close"; comparison table shows "improved" | "Retry and compare" |
| 72–85 s | Step out of frame → "Feedback withheld: your legs were below the bottom edge" | "It says when it can't see you, instead of guessing" |
| 85–90 s | README / GitHub page | "Open source; evaluation and limitations in the repo" |

Tips: record the screen at 1080p, with the browser zoomed to 110%; use your own footage or a friend's with
permission; keep the real camera feed visible during recording; upload the video and link it in the README.
